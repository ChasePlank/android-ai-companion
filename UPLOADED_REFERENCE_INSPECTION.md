# Uploaded reference audio and alternate avatar

Inputs are RoxyAreYouLost.ogg.ogx, Roxanne_Wolf_Toggle.glb and the original roxanne_wolf_security_breach.glb. The alternate GLB is a 3D avatar, not another voice checkpoint. Their Git blob identities are pinned to the observed uploads; changed inputs fail rather than being silently accepted. No deserialization of voice checkpoints or execution of uploaded model code is involved.

Actions > Inspect Roxy reference and alternate avatar runs automatically when this job/helper or its inputs change, or manually. Download roxy-upload-inspection and paste inspection.txt. inspection.json and the original/alternate node CSVs provide details. The artifact also includes reference-are-you-lost.wav and reference-pitch.csv after successful audio processing. Partial results may be present if a later step fails; check the report stage. Artifacts expire after seven days.

FFprobe detects the actual audio format regardless of the doubled extension. FFmpeg decodes a mono 16-bit analysis WAV at the source rate. Stereo, if present, is downmixed for analysis; the original upload is untouched. Duration and non-silence are checked. Pitch estimates preserve unvoiced frames and do not establish pronunciation, accent, emotional intent or style-transfer capability. This is not a claim that the assistant has listened to the reference.

The GLB inspection checks the JSON header/metadata and inventories nodes, named parent relationships, declared local transforms, joints, animations, morph targets, materials, images, external resources and extensions. Duplicate names are excluded from unique-name comparisons. Text matches like jaw or eye are leads, not verified anatomy. Detailed vertex attributes, inverse-bind matrices, deformation, axis calibration, visual appearance and on-device rendering are not validated. Structural overlap alone is not permission to reuse the original jaw/blink/gaze calibration.

This inspection does not add a model selector, replace the current avatar, modify uploaded files, train an accent, change conversion settings or produce an APK. A later implementation should be separately reviewed only after the report identifies compatibility and per-avatar calibration requirements. The job uses CPU, dependency downloads, normal Actions usage, read-only repository permissions and a 15-minute timeout. Reference and avatar distribution rights remain the user's responsibility; no license clearance is claimed.
